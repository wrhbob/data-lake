# pdf_page_extract — 输入输出规范

> 单一入口:`pdf_page_extract.py`
> 依赖: `PyMuPDF` (`import fitz`)、标准库 `argparse`/`re`/`sys`/`pathlib`。
> Python 环境:DLSE(`/d/miniconda3/envs/DLSE/python.exe`)。

---

## 0. 一句话

把一个 PDF 里**指定页码**的页面**抽出并合并**为**单个**新 PDF，跨页连续保留页内内容（不重排、不缩放、不 OCR、不解析结构）。

---

## 1. CLI 签名

```
python pdf_page_extract.py <pdf> <pages> [-o OUTPUT]
```

| 位置 / 标志 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `<pdf>` | 路径 | ✅ | 源 PDF,绝对或相对路径均可 |
| `<pages>` | 字符串 | ✅ | 页码规格,见 §2 |
| `-o` / `--output` | 路径 | ❌ | 输出 PDF 路径;缺省按 §5 推导 |

---

## 2. 输入 · 页码规格 `<pages>`

**页码采用 1-indexed 编号**(与主流 PDF 阅读器一致,即 PDF 的"第 1 页"是 `1`,不是 `0`)。

### 2.1 合法 token

| 写法 | 含义 |
|---|---|
| `5` | 单页,第 5 页 |
| `5-8` | 闭区间,第 5、6、7、8 页(`start <= end`) |
| `5-5` | 单页(`5-5` 等价于 `5`) |

### 2.2 多个 token 之间用半角逗号 `,` 分隔

| 完整字符串 | 含义 |
|---|---|
| `2` | 仅第 2 页 |
| `2-4` | 第 2、3、4 页 |
| `2,4-5,7` | 第 2、4、5、7 页(混合) |

### 2.3 容忍空白

token 内、token 之间的空格 / Tab 都会忽略:

```
2, 4 - 5 , 7     → 第 2、4、5、7 页
2 -4              → 第 2、3、4 页
```

### 2.4 顺序与去重

- **保留出现顺序**:输出 PDF 的页面顺序 = 输入字符串 token 的展开顺序(单页本身、跨区间都不重排)。
- **自动去重**:同一页在规格里多次出现只保留首次出现的位置。如 `2,2,3` → 输出顺序 `[2, 3]`。

### 2.5 不接受的形式

| 写法 | 拒绝原因 |
|---|---|
| `2-` | 区间无 end(应写 `2-2` 或 `2`) |
| `5-2` | 区间反向 |
| `0` 或 `2-0` | 起始 < 1 |
| `2, ,4` | 空 token(`split(",")` 中出现空串) |
| `2..4` | 非法字符 |
| `abc` | 非法字符 |
| `2,4-` | 区间缺 end |

非法形式 → 退出码 `3`,stderr 输出错误,**不写任何输出文件**。

---

## 3. 输出 · PDF 行为

| 项 | 说明 |
|---|---|
| 格式 | 标准 PDF(PDF 1.7 / 视 fitz 而定) |
| 总页数 | = 抽出的页数(去重后) |
| 单页内容 | **逐位复制**原 PDF 该页(不重排版、不缩放、不 OCR、不改字体) |
| 顺序 | 见 §2.4(按输入 token 展开顺序、去重) |
| 元数据 | 保留源 PDF 的 metadata;PyMuPDF 默认行为不主动改写 |
| 文件存在性 | 成功一定写出文件;任何失败都不写半成品(原子语义) |

---

## 4. 退出码与错误处理

| 退出码 | 含义 | 触发条件 | 是否写输出文件 |
|---|---|---|---|
| `0` | 成功 | 抽取 + 写出完成 | ✅ 已写 |
| `2` | 源 PDF 不可访问 | 文件不存在 / 不是文件 / 无法打开(损坏、加密、未实现解码器等) | ❌ 不写 |
| `3` | 页码规格格式非法 | 见 §2.5 列举的所有形式 | ❌ 不写 |
| `4` | 页码**超出** PDF 总页数范围 | 至少有一个 token 展开成 `> total_pages` 或 `< 1` | ❌ **绝不写**(即使"越界页是第 99 个、其他 98 页合法"也不写半成品) |
| `5` | 抽取 / 写入失败 | fitz 抛异常(磁盘满、权限、被信号打断等) | ❌ 不写(已清理可能残留) |

所有错误信息走 **stderr**,成功摘要走 **stdout**,便于 shell 管道。

---

## 5. 输出路径推导(`-o` 缺省时)

设 `<pdf>` = `DIR/<stem>.pdf`,解析后**页码序列**(去重、保序)为 `pages`。

1. 把 `pages` **排序后**做相邻合并:`[2,3,4,5,7]` → `"2-5,7"`。
2. 默认输出:`DIR/<stem>_p<压缩序列>.pdf`。

例:

| 输入 PDF | `<pages>` | 默认输出 |
|---|---|---|
| `Data/foo.pdf` | `2,4-5,7` | `Data/foo_p2,4-5,7.pdf` |
| `Data/foo.pdf` | `5` | `Data/foo_p5.pdf` |
| `D:/x/y.pdf` | `2, 4-5 ,7` | `D:/x/y_p2,4-5,7.pdf` |

---

## 6. 报告输出(stdout)

成功时打印五行摘要:

```
[完成] 源 PDF      : <src>
[完成] 源总页数    : <total>
[完成] 抽出页数    : <written>
[完成] 页码清单    : <pages>  (1-indexed,按输入顺序,已去重)
[完成] 输出文件    : <out>
```

`<pages>` 字段是**最终写入的页码清单**(展开、去重、保序),便于复核"输出 PDF 里有哪些页"。

## 7. 端到端示例

### 7.1 成功路径

```bash
PY=/d/miniconda3/envs/DLSE/python.exe

# 抽第 2 页
$PY pdf_page_extract.py "Data/foo.pdf" "2"
# → Data/foo_p2.pdf

# 抽 2-4(等价于 2,3,4)
$PY pdf_page_extract.py "Data/foo.pdf" "2-4"
# → Data/foo_p2-4.pdf

# 抽 2,4-5,7(混合)
$PY pdf_page_extract.py "Data/foo.pdf" "2,4-5,7"
# → Data/foo_p2,4-5,7.pdf

# 显式指定输出
$PY pdf_page_extract.py "Data/foo.pdf" "2,4-5,7" -o /tmp/out.pdf
# → /tmp/out.pdf

# 去重:2,2,3 → 第 2、3 页(保序)
$PY pdf_page_extract.py "Data/foo.pdf" "2,2,3"
# → Data/foo_p2,3.pdf
```

### 7.2 失败路径

```bash
# 假设 foo.pdf 只有 50 页
$PY pdf_page_extract.py "Data/foo.pdf" "2,99"
# stderr:
#   [错误] 页码超出范围: [99] 不在 [1, 50]
#     源 PDF 总页数: 50
#     合法范围: 1-50
#     不写任何输出文件,程序停止。
# 退出码: 4
# 检查:Data/foo_p*.pdf 不存在(没有半成品)
```

```bash
# 非法规格
$PY pdf_page_extract.py "Data/foo.pdf" "2-"
# stderr: [错误] 页码规格非法: 页码规格 token 非法: '2-' (期望 '5' 或 '5-8' 形式)
# 退出码: 3
```

```bash
# 区间反向
$PY pdf_page_extract.py "Data/foo.pdf" "5-2"
# stderr: [错误] 页码规格非法: 区间反向 (start > end): '5-2'
# 退出码: 3
```

## 8. 边界与已知限制

| 项 | 行为 |
|---|---|
| **加密 PDF** | 需要密码才能打开 → 视为"无法打开",退出码 `2`(不实现自动解密)。 |
| **损坏的 PDF** | fitz 抛异常 → 退出码 `2`,不写输出。 |
| **重复页** | 内部去重(`pages` 字典),最终 PDF 不含重复页(见 §2.4)。 |
| **超大区间** | `1-999999` 在总页数 < 999999 的源上 → 退出码 `4`(越界),不写。 |
| **页码用 0 或负数** | 退出码 `4`(越界)— 不允许 `0` 作为有效页。 |
| **空白 PDF / 0 页** | fitz 通常仍能打开;`pages=[]` 时脚本已在解析阶段退出码 `3`。 |
| **输出目录不存在** | 自动 `mkdir -p`(parents=True)。 |
| **输出与源同名** | `2` → `foo_p2.pdf`,**不会**覆盖源 PDF;若用户显式 `-o foo.pdf` 把输出写成源同名,fitz 写到源路径 → 自己覆盖自己,**不退码但内容丢失**;不防护。 |

## 9. 与已有 `cut_test_pdf.py` 的差异

| 维度 | `cut_test_pdf.py`(一次性脚本) | `pdf_page_extract.py`(本规范入口) |
|---|---|---|
| 入参 | 路径硬编码 | CLI 参数化 |
| 页码格式 | 单一连续区间 | 单页 / 区间 / 混合 |
| 范围校验 | 无 | 显式,越界 → 退出码 4 + 0 输出 |
| 输出合并 | 单文件(单区间) | 单文件(多 spec 也能合一) |
| 默认文件名 | 固定写死 | 按 spec 自动推导 |
| 退出码 | 仅 `print` | 5 个退出码分级,便于自动化 |
| 错误处理 | 无 try / 异常上抛 | 包 try/except,失败清理半成品 |

`cut_test_pdf.py` 保留作为历史一次性脚本;**新工作统一走 `pdf_page_extract.py`**。
