# P0-5A 筛选区简化变更计划 v0.1

**状态：`PLAN_ONLY`**（审核通过前不修改代码）

## 0. 问题诊断

当前筛选区将「版次」「分册专业」长期固定展示在主筛选行，且 API 未就绪时摆出 4 个禁用下拉框，每个都写"待接入 facets"。表现：

| 问题 | 现状 | 影响 |
| --- | --- | --- |
| 版次固定展示 | 4 个禁用下拉中包括"版次" | 大多数定额一年只有一版，版次不是主筛选维度 |
| 分册专业暴露在一级 | 与地区/行业/年份并列 | 分册专业是细节入口，不应占据主筛选位 |
| 地市兼容性不佳 | "建筑工程定额"下弹出一个独立"地市"下拉 | 多数定额覆盖全省，地市筛选不常用 |
| 4 个禁用下拉 + 各自写"待接入" | API 未就绪时每行都标 | 视觉噪音大，用户阅读负担重 |
| 下拉框交互不如 tag | 当前用 `<select>` | 选中状态不明显，单值筛选用标签式更直观 |

## 1. 设计原则

> 主筛选只保留两级维度，版次按需出现，其余全进高级筛选。

- **两级主筛选**：一级分类决定了二级是什么（地区 / 行业分类 / 适用范围）。
- **标签式（chip）选择**：单值筛选用可点选 tag 代替下拉，视觉更直观。
- **版次条件出现**：同一年存在多版本时才显示。
- **未就绪兜底**：一条简洁提示代替 4 行禁用控件。

---

## 2. 一级分类 → 二级筛选映射

| 一级分类 | 二级筛选 | 说明 |
| --- | --- | --- |
| 全部 | 无 | 不显示级联行，只保留「高级筛选」入口 |
| 清单规范 | 适用范围 + 年份 | `scope` + `edition_year` |
| 建筑工程定额 | 地区 + 年份 | `jurisdiction_code` + `edition_year` |
| 专业工程定额 | 行业分类 + 年份 | `industry_sector_code` + `edition_year` |

切换一级分类时：清空二级维度选中值（重置为 `"all"`）、清空年份、清空版次。

---

## 3. 标签式选择（替代下拉）

```text
地区    全部  四川省  北京市  重庆市  浙江省  …
年份    全部  2025  2022  2020  2018

行业分类  全部  电网工程  水利工程  铁路工程  …
适用范围  全部  房屋建筑与装饰  通用安装工程  …
```

交互：
- 点击 tag → 单选（替代原有下拉单选语义）；
- `<select>` 替换为可滚动的 `<div class="filter-chip-group">` 包裹多个 `<button class="filter-chip">`；
- API 未就绪时所有 tag 置灰，居中显示一行提示。

实际数据来自 facets API。API 未就绪时标签区静态展示「待接入」提示，不渲染假选项。

---

## 4. 版次条件出现

版次是否显示由 facets 返回的年份 → 版次数决定：

* 某年份只有 1 个版次 → 版次行隐藏，无需筛选；
* 某年份有 2+ 个版次 → 年份选中后，版次行出现在年份下方；
* 默认选中"全部版次"。

版次也以 tag 形式展示。

API 未就绪时版次行不显示（因为连年份数据都没有）。

---

## 5. 高级筛选（折叠区内容）

以下维度从主筛选区移除，全部进入 `<details>` 高级筛选折叠区：

| 维度 | 来源 | 说明 |
| --- | --- | --- |
| 分册专业 | `discipline_code` | 原主筛选 |
| 资料性质 | `material_type` | 已在文案中，补正式选项 |
| 地市 | `jurisdiction_code`（市级） | 原主筛选"地市" |
| 发布单位 | `issuer_name` | 新增 |
| 元数据状态 | `metadata_status` | 新增 |
| 档案状态 | `archive_status` | 新增 |
| 入湖通道 | `source_channel` | 新增 |
| 文件格式 | `file_format` | 新增 |

高级筛选区内各维度使用多选 checkbox 或 tag 多选（取决于后端 facets 返回的基数）。

---

## 6. API 未就绪时的兜底提示

当前：

```text
[地区] [待接入facets]  [地市] [待接入facets]  [年份] [待接入facets]  [版次] [待接入facets]  [分册专业] [待接入facets]
```

改为一条居中提示：

```text
分类与年份筛选待接入数据接口。
```

不渲染任何禁用下拉框或假 tag。高级筛选入口保留但内部同样只显示接入提示。
